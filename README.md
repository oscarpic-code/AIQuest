# AIQuest

AIQuest es una web sencilla de aprendizaje con un mini juego para practicar la identificación de titulares reales de noticias sobre inteligencia artificial.

## Características

- Pantalla de inicio con título AIQUEST y botón de comienzo.
- Mini juego sin login.
- Tres opciones de titular: una real y dos alteradas.
- Enlace a la noticia original al finalizar la ronda.

## Ejecutar localmente

Puedes abrir el archivo index.html directamente en un navegador o servirlo con un pequeño servidor local:

```bash
cd C:/workspace/AIQuest
python -m http.server 8000
```

Luego entra en http://localhost:8000.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube estos archivos:
   - index.html
   - README.md
3. En la configuración del repositorio, activa GitHub Pages y elige la rama principal como fuente.

La web queda lista para ser vista públicamente sin login.
